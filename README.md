# 3D Scene Renderer

I'm building a 3D Scene Renderer as a Computer Graphics project to understand how 3D objects are created, transformed, and displayed on a screen.

The main goal of this project is to create a virtual 3D environment where objects can be added, moved, rotated, and viewed from different camera angles. I'll also be working on lighting, textures, and other rendering techniques to make the scenes look better.

## Features

- Creating basic 3D objects like cubes, spheres, and pyramids.
- Moving, rotating, and scaling objects.
- Camera movement and positioning.
- Adding lights and shadows.
- Applying textures to 3D objects.
- Rendering 3D scenes in real time.

## Technologies Used

- C++
- OpenGL
- GLFW
- GLAD
- GLM
- CMake

## What I'm Learning

Through this project, I'm exploring how computer graphics work behind the scenes, especially 3D transformations, coordinate systems, camera projections, lighting, and the rendering pipeline.

## Future Plans

I plan to improve the renderer by adding more objects, better lighting, shadow effects, texture support, and interactive scene controls.

## Project Status

Currently in development. I'll keep improving it and adding new features as I learn more about computer graphics.
